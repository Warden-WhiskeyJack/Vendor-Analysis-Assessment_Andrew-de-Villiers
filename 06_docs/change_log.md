# Change Log

## Purpose
Track all manual corrections and adjustments made to vendor data after QA review.

---

## Log Format

| Date | File Changed | Row/Vendor | Field | Before | After | Reason | Reviewer |
|------|--------------|------------|-------|--------|-------|--------|----------|
| 2026-01-15 | vendors_prefilled.csv | Row 42 (Acme Corp) | department | Marketing | Sales | Vendor is CRM tool, should be Sales not Marketing | AV |
| 2026-01-15 | batch_003_output.csv | Row 8 (XYZ Inc) | suggestion | Terminate | Consolidate | Used by multiple teams, consolidation more appropriate | AV |

---

## Instructions

1. **Date**: Use ISO format (YYYY-MM-DD)
2. **File Changed**: Specify full filename and location if ambiguous
3. **Row/Vendor**: Include row number and vendor name for clarity
4. **Field**: Column name that was changed
5. **Before**: Original value
6. **After**: New value
7. **Reason**: Brief explanation for the change (business logic, error correction, etc.)
8. **Reviewer**: Initials of person who made the change
